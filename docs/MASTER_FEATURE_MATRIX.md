## Verdicts

| Verdict | Meaning |
|---|---|
| `NOT STARTED` | Requested behavior has no dependable implementation or proof. |
| `IMPLEMENTED, UNPROVEN` | Code exists, but no valid current-version live proof exists. |
| `PARTIAL` | Some real behavior works, but the requested end-to-end result does not. |
| `FIXTURE PASS` | Automated fake-page or parser test passes; this is not live proof. |
| `LIVE PROVEN, AWAITING APPROVAL` | Current-version Profile 2 evidence and exact readback pass; user gate approval is still pending. |
| `LIVE PASS` | Current-version Profile 2 evidence and exact readback prove the workflow. |
| `BLOCKED` | An external limitation prevents progress and is documented with evidence. |
| `OUT OF SCOPE` | The user explicitly excluded the capability from this reliability program; it is not counted as a remaining gate. |
