| `IMPLEMENTED, UNPROVEN` | Code exists, but no valid current-version live proof exists. |
| `PARTIAL` | Some real behavior works, but the requested end-to-end result does not. |
| `FIXTURE PASS` | Automated fake-page or parser test passes; this is not live proof. |
