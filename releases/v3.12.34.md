# GLDN Ops v3.12.34 - Mark as Shipped Approval Recovery

## Changes

- Treats a nested eBay menu row and its button as one Mark as Shipped action, while still rejecting separate ambiguous targets.
- Rechecks selected order counts and the Shipping menu immediately before activation.
- Distinguishes a confirmed pre-click failure from an attempted or uncertain shipment click. Only a confirmed no-click result allows another fresh approval; no automatic retry occurs.
- Keeps the page clickable outside the approval panel and restores usable close controls after failure. Closing an uncertain review does not clear its saved dispatch evidence.
- Never treats the GLDN approval panel as eBay's own confirmation.
- Includes all v3.12.33 policy-audit checkpoint and classification-progress repairs.

## Update and Recover

On the affected Computer 2 profile, reload the eBay tab to remove the old stuck overlay, then inspect the current order statuses. Use GLDN Ops **Update & Reload** and confirm **v3.12.34**. Reload the eBay page to replace its old content script.

If an old active workflow blocks updating, do not blindly reset it or repeatedly approve. Install the current GLDN Ops Setup into the same existing loaded folder and reload the same extension in Chrome. Keep the same profile, extension ID, and stored data. Do not uninstall or clear storage. See the installation guide for nonstandard loaded folders.

Start Mark as Shipped again only after checking which orders still await shipment. Review and approve the displayed selection. If the repair reports that a click may have happened, close the panel and inspect eBay rather than retrying.
