# GLDN Ops v3.10.1

## Scope

- Correct the public one-time installer on Windows PowerShell 5.1.
- Preserve all verified-update, rollback, stable-folder, and marketplace safety behavior from v3.10.0.

## Fix

The first public v3.10.0 setup run downloaded and validated the main package,
then stopped before updater registration because PowerShell 5.1 rejected the
UTF-8 BOM GitHub served at the beginning of `latest.json`. v3.10.1 writes new
metadata without a BOM and also strips a BOM defensively before parsing.

## Verification

- The failure was reproduced against the public GitHub raw metadata on Windows PowerShell 5.1.
- The parser and metadata writer now have an exact BOM-tolerance regression contract.
- The complete JavaScript release gate passes `227/227`.
- The destructive updater fixture passes verified update, config preservation, rollback, bad-checksum rejection without mutation, and no-admin loopback service checks.
- The one-time installer fixture passes stable-folder creation, private dashboard seeding, and updater configuration.
- The freshly downloaded public Setup installed v3.10.1 on Windows PowerShell 5.1, seeded the private dashboard configuration, registered the Startup agent, and returned a healthy loopback status.
- A public-package round trip passed `3.10.0 -> 3.10.1 -> 3.10.0 -> 3.10.1`; the private configuration hash remained unchanged through both updates and rollback.
- Marketplace pages and Profile 2 were not changed during this repair.
