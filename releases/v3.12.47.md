# GLDN Ops v3.12.47

Released: 2026-10-04

## Optional Extension Setup

Open the **GLDN Ops Chrome icon > Optional Extension Setup**. The page is now
included in both download formats and opens on a fresh install. Normal updates
do not open it.

- **Download latest eComSniper** opens the provider and, after optional download
  permission, saves its observed current version in a versioned Downloads folder.
  Reuse the profile's signed-in session or sign in when asked. Download completion
  must be confirmed by Chrome; extraction and Load unpacked remain manual.
- **Open Trackerbot in Chrome Web Store** opens the official listing. Choose
  Add to Chrome and approve Chrome's confirmation yourself.
- **Open Trackerbot sign-in** opens its official website. Any separate extension
  login and verification remain in Trackerbot.

Neither option runs merely because this page opens. Provider passwords are
used only for an explicit sign-in and are not included in the release.

## Dashboard Default

The owner explicitly approved publishing the live shared dashboard read/write
key in this public GitHub release. Fresh profiles seed that default automatically;
existing saved connections and local private overrides are preserved through
updates. No repeated setup-code entry is normally needed.

This key is public and is not an access-control boundary against downloaders.
It authorizes dashboard record reads and writes, not just opening a sheet link.

**Connection boundary:** the existing dashboard address returned Google HTTP 403
in release-time connection tests. The key is included, but Google deployment
access still needs verification. The UI distinguishes configured settings from
a successful Test Connection or confirmed sync.

## Verification

- Executable tests cover optional provider actions, exact download routing,
  interruption/recovery, credential non-persistence, first-install-only launch,
  automatic dashboard defaults, preservation of existing settings and malformed
  default rejection.
- Package checks require all setup files and the explicitly approved default.
  Unrelated private configuration and provider passwords remain excluded.
- Synthetic browser checks do not certify completed provider downloads, installed
  Trackerbot, provider authentication or live dashboard connectivity.
- No marketplace order, listing, purchase or saved note was changed.
