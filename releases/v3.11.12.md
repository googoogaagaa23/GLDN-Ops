# GLDN Ops v3.11.12

## Scope

- Reuse the existing signed-in Chrome Profile 2 for reliable live verification.
- Eliminate accidental unsigned-profile launches.
- Preserve every existing marketplace approval boundary.

## Profile 2 Control

- The existing updater exposes a localhost-only command queue on `127.0.0.1`.
- A random per-install token authenticates both the operator controller and extension worker.
- Commands are accepted only when exactly one matching GLDN Ops unpacked instance is loaded in Profile 2.
- The controller never launches Chrome or creates a profile.
- Approved actions are limited to session/page inspection, safe tab focus/open/reload, approved GLDN state reads, and named review-only workflow launch.
- Approved hosts are limited to eBay, Amazon, Poshmark, and EcomSniper.

## Marketplace Safety

- Arbitrary JavaScript, selectors, and click commands are unsupported.
- `submit` and other unknown actions are rejected by the updater before they reach Chrome.
- eBay Submit, Save, Apply, Continue, Mark as shipped activation, purchases, and equivalent irreversible actions remain manual approval stops.
- Reload is refused while a workflow or review gate is active.
- The bridge uses the computer's existing Chrome connection and public IP. It does not use a proxy, VPN, cloud browser, or remote marketplace session.

- Missing-token requests are rejected.
- An attempted arbitrary `submit` command is rejected.
- PowerShell source parses cleanly.
