# GLDN Ops v3.10.5

## Scope

- Prevent GLDN appearance settings from changing the host marketplace page.
- Preserve every GLDN theme inside the panel, modals, popup, onboarding, and guide.
- Clean theme settings left by older GLDN content scripts after a page refresh.

## Theme Isolation Repair

- Host pages no longer receive the generic `data-theme` attribute.
- Host pages no longer receive an inline root `color-scheme` value from GLDN.
- Short extension-page aliases such as `--bg`, `--panel`, and `--ink` are no longer published on marketplace roots.
- GLDN surfaces use the namespaced `--gldn-color-scheme` token and retain the selected theme.
- When an older GLDN script is detected, matching legacy settings are removed without deleting unrelated site-owned values.

## Safety

- This release changes appearance scoping only.
- It performs no listing, order, message, payment, or spreadsheet action.
- Existing marketplace approval stops are unchanged.

- The computer was released immediately when requested. Post-update visual confirmation on eBay Messages and Poshmark remains pending.
