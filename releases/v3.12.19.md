# GLDN Ops v3.12.19

## What changed

- Monthly eBay Profit now detects an unexpectedly closed background worker.
- The run immediately changes from Running to a resumable Paused checkpoint.
- The page reports why it paused and directs the operator to Resume.
- Status reads repair stale active state when Chrome missed the original tab-close event.
- Starting a new month repairs stale state before checking whether another run is active.

## Unchanged behavior

- A worker that closes normally after reaching review or completion does not create a false interruption.
- Read 1 remains saved-note earnings minus saved-note Amazon cost.
- Read 2 remains visible eBay earnings minus the exact matched Amazon order-item cost.
- No order, listing, note, purchase, or spreadsheet write occurs during worker recovery.

## Verification

- Focused monthly-profit and dashboard tests cover independent profit reads and unexpected worker closure.
- The complete JavaScript and release suites must pass before updater publication.
- Live M0 confirmation remains the final runtime check because M0 exposed the original failure.
