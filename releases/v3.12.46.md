# GLDN Ops v3.12.46

Released: 2026-10-03

## Amazon ETA

Amazon's selected shipment heading "Arriving by Oct 7, 2026" now populates **10/7** in Review Amazon Information. Arriving on and the previous Arriving format also work. Dates loaded after the review opens are picked up without replacing a manual correction.

## Visible eBay Note

Order Details now includes a **GLDN Order Note** box beneath the page heading, independent of the collapsed side panel. Choose **Use copied Amazon info**, or paste copied information into **Editable note** when switching Chrome profiles. Check the buyer, address, item and amounts, tick the review checkbox, then choose **Fill eBay note**. Review and click eBay's **Save** yourself.

Checkout information is an estimate, not proof that an Amazon purchase was placed. This manual draft path does not sync profit. The existing **Prepare Order Note** workflow still requires exact supplier-order evidence for verified profit.

Drafts reset on order navigation. Known ASIN mismatches and stale imported information are rejected. Native note filling still works when clipboard permission is unavailable.

## Update

Use **Update & Reload** on each GLDN profile, then refresh both Amazon and eBay tabs. Confirm the extension reports **3.12.46**. Publishing this release does not automatically prove every computer has installed it.
