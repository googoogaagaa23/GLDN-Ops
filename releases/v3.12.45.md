# GLDN Ops v3.12.45

Released: 2026-09-14

## Listing Checks Without Dashboard Setup

Existing Listings Policy Audit and Listing Policy Check now work without a dashboard setup code. A missing connection, unavailable server, invalid shared response or slow history refresh no longer stops listing checks, saved-audit reclassification or exact batch validation.

The bundled policy rules and locally saved/cached removal incidents still apply. A separate warning identifies potentially missing newer incidents from other profiles. Pesticide, spray-can and IP restrictions, Ready-only copying, account checks and exact batch-End approval remain unchanged. Explicit Sync Shared History still requires a working connection and verified remote acknowledgement.

Use Update & Reload on each computer, reopen the listing check, and start/resume the scan. For an existing saved audit, use Refresh Policy Checks. No dashboard code is needed for these listing checks.
