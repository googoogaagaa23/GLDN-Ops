# GLDN Ops v3.12.16

## What changed

- Prepare Order Note no longer depends on browser clipboard access after the Amazon review is approved.
- The reviewed Amazon order handoff is saved inside GLDN Ops first and selected by exact eBay SKU/ASIN evidence.
- Missing, stale, wrong-order, and mismatched evidence now open a visible recovery window instead of looking like an inactive button.
- Popup-triggered Prepare Order Note now waits for and displays the real page result.

## Safety

- The exact Amazon order ID, order-details source, ASIN set, positive cost, and two-hour evidence age are still required.
- A product page, checkout page, recommendation price, stale handoff, or mismatched order fails closed.
- GLDN Ops fills only the real eBay Add/Edit note textarea and stops before eBay Save.
- No new profit row is synced before eBay visibly saves the note.

## Verification

- Focused Amazon order-detail, eBay order-note, and popup contracts pass.
- The complete release gate verifies source parsing, packages, updater checksums, clean install, rollback, and all JavaScript contracts.
