# GLDN Ops v3.10.2

## Scope

- Remove the unsupported Bulk Listing workflow claim.
- Replace it with a truthful, read-only EcomSniper handoff monitor.
- Repair the Windows one-time Setup experience so it is visible and reliable.

## Behavior

- GLDN can report a verified seller-extraction phase and count reconciliation on eBay.
- GLDN can report whether a Scanner or Product Hunter tab that it opened is still open or has closed.
- GLDN cannot read EcomSniper private-page progress, Bulk Poster counts, or completion.
- Stop GLDN Assist affects only GLDN's extraction queue.

## Safety

No EcomSniper listing control is clicked. No marketplace listing is created, edited, submitted, or finalized by this change.

## Windows Setup

- Setup opens a visible progress window and keeps the final result onscreen.
- Setup records its transcript at `%LOCALAPPDATA%\GLDN Ops Installer\latest.log`.
- Reinstalling stops only the existing GLDN updater that holds the stable folder, preserves a backup, and restarts the updater after installation.
- The previous silent-window behavior and updater folder-lock failure are covered by release checks.

## Verification

- Focused monitor and popup contracts must pass.
- The complete release gate must pass before packaging.
- The complete release gate passes `228/228`, including a reinstall while the updater is running.
- Signed-in Profile 2 UI proof remains required before this feature is called live-ready.
