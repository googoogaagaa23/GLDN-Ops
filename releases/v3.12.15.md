# GLDN Ops v3.12.15

## What changed

- Added a Profile 2-only control action for a complete read-only Existing Listings Policy Scan.
- The action safely cancels an abandoned policy End review before starting fresh.
- It returns exact total, no-match, review, and reviewed Block counts when the full store scan completes.

## Safety

- The control action cannot prepare, approve, or submit a listing End.
- Canceling an abandoned review changes only saved extension state and returns its eBay tab; it does not change a listing.
- Any future End still requires a visible native eBay review and exact `APPROVE END POLICY LISTINGS N` authorization.

## Verification

- Focused policy-audit and Profile 2 control contracts prove the action is read-only.
- The complete release gate verifies source parsing, packages, updater checksums, clean install, rollback, and all JavaScript contracts.
