# GLDN Ops v3.12.28

Released: 2026-08-26

## Live Profit Progress

- Historical Poshmark Profit Start and Resume open one reusable `Profit Run Progress` tab.
- The progress page survives popup closure and reads the existing durable checkpoint without starting duplicate work.
- It shows the current phase, current Poshmark order or Amazon ASIN, indexed/detail/match/review counts, exact staged profit, errors, pause reason, Amazon profile, and destination tabs.
- Resume, Pause Safely, Show Current Page, Open Review, and Reset Checkpoint are available from the progress page.
- The popup and Poshmark launcher both provide an explicit Open Live Profit Progress control.

## Spreadsheet Visibility

- A successful explicitly approved Poshmark sync opens or focuses the actual Poshmark profit workbook.
- eBay Amazon-cost resolution opens or focuses the shared profit workbook instead.
- Queued, failed, or unapproved work does not open a workbook as if its rows were already saved.
- Existing saved workbook rows remain available from direct buttons on the progress page while in-progress rows remain local until approval.
