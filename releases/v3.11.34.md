# GLDN Ops v3.11.34

Date: 2026-08-02

## Computer 2 Mark as Shipped Hotfix

Computer 2 / FANCYFI correctly selected all 4 of 4 awaiting orders, but the first approved eBay `Mark as shipped` action did not open eBay's confirmation. The old path depended on a synthetic page click that was not reliable across computers.

This release replaces that first activation with one trusted Chrome press/release. It requires the exact approved count, owner tab, Awaiting Shipment URL, one enabled non-GLDN target, and a successful hit test. It records dispatch before the press, records release afterward, detaches the debugger, and never retries the action.

The second eBay confirmation remains a separate trusted action and still requires its own exact-count approval. Updating clears an unfinished Mark as Shipped run from the previous extension context.

Completed and saved Move .99 summaries are now passive. A stale review-request flag is cleared during update, a summary opens only after a fresh explicit workflow request, and saved results no longer expose the page panel on ordinary Listings visits.
