# GLDN Ops v3.11.2

## Scope

- Repair the Mark as Shipped approval boundary found during the full source audit.
- Keep marketplace styling isolated to GLDN-owned panels and windows.
- Make abandoned workflow recovery available from the universal panel.
- Preserve the exact loaded-folder updater and saved Chrome-profile settings from v3.11.1.

## Marketplace Safety

- Mark as Shipped now stops before activating eBay's Mark as shipped command.
- The first approval is bound to the exact verified selected count.
- If eBay then presents Continue, the extension stops again and only the operator may click Continue after a fresh approval.
- Unknown outcomes, stale approvals, and interrupted pages fail closed and cannot silently restart the action.

## Interface Isolation

- The universal panel now exposes a confirmed Reset control for abandoned local workflow state.
- Generic health-status CSS selectors were removed so marketplace elements cannot inherit GLDN status colors.

## Verification

- Focused contracts cover the new activation boundary, separate Continue boundary, universal Reset, and host-page selector scope.
- The full JavaScript suite, syntax checks, updater fixtures, generated-guide drift check, package inspection, and release gate must pass before Profile 2 is updated.
- Signed-in Chrome Profile 2 / computer `0` / FAK12 is the only accepted live browser for this launch.
- The live launch must verify version, identity, dashboard connection, Store-category settings, and idle workflow state before feature tests.
- No marketplace Continue, Save, Submit, purchase, or equivalent final action is authorized by this release note.
