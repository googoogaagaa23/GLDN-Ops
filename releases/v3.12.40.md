# GLDN Ops v3.12.40

## Changes
- Existing Listings Policy Audit opens in Block + Review, showing both classifications together without no-match rows.
- Select All Block + Review selects both categories across all results pages and returns to the combined view.
- Select Filtered Flags and the page checkbox remain available for narrower selections.
- Mixed Block/Review batches use the existing native eBay review, exact approval and maximum of 200 items per batch.
- Already-ended and unconfirmed-batch IDs remain excluded from new batches. No policy-rule changes.

## Use
Update to v3.12.40 and reopen Existing Listings Policy Audit. Existing results remain saved; no new scan is needed just for the combined view.

Choose Select All Block + Review, then Review Selected on eBay. Inspect the exact mixed batch and approve it through GLDN or eBay, not both. Check eBay Result reconciles a batch ended directly on eBay.

## Verification
- Unit regression covers the screenshot's 58 Block plus 126 Review as one 184-item selection, spanning two display pages.
- Isolated Chrome checks at 1440, 900 and 540 pixels cover mixed results, global selection from a narrowed search, 200-plus-1 batches, approval, and unconfirmed-batch protections.
- Existing result-recovery tests remain in the full release suite. No signed-in live listing was ended for this release.
