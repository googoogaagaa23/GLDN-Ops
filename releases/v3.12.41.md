# GLDN Ops v3.12.41

## Changes
- Existing Listings Policy Audit now defaults to All rows, showing every matching result in one scrollable list.
- Rows per page offers 100, 250, 500 and All. Switching sizes returns to the first row without clearing selections.
- Classification filters and search still apply. Block + Review shows both flagged types together; All classifications also includes no-match results.
- Showing all rows does not change exact approval, the 200-item End batch limit, or ended/unconfirmed-batch exclusions.

## Use
Update & Reload, then reopen Existing Listings Policy Audit. Existing audit results remain saved; no rescan is needed for this display change. Rows per page is above the results and defaults to All.

## Verification
- Unit regressions cover All by default, 100/250/500 page sizes, changing sizes from a later page, empty results, preserved selections, and the unchanged 200-item batch limit.
- Isolated Chrome checks cover desktop and narrow viewports, scrolling to the last row, combined selection, exact approval and result recovery.
- A 19,444-listing sample confirms the complete list renders, the final row is reachable without Next, and searching still works.
- No signed-in marketplace listing was ended for this release.
