# GLDN Ops v3.11.0

## Scope

- Make cross-computer updates and interrupted workflows fail closed instead of racing, looping, or silently resuming stale code.
- Keep the local unpacked deployment and one-click Update & Reload path already installed on each computer.
- Retire unsupported EcomSniper automation and report only GLDN-observable handoff state.
- Preserve every marketplace approval boundary while preparing a complete signed-in Profile 2 live launch.

## Reliability Repairs

- One shared workflow lock protects active runs and open review windows.
- Update, reload, and rollback are blocked while a workflow or approval window is active; automatic update checks defer safely.
- Update requests are bound to the requesting Chrome extension ID and Chrome's own loaded-folder record. The updater cannot silently modify a disconnected copy or accept a target path from a page.
- Resumable eBay, Amazon, Poshmark, Walmart, review, and handoff state is stamped with the running extension version.
- Old-version state is cleared or paused at a saved checkpoint before new code can resume it.
- Invalidated content scripts release listeners and observers, disable stale controls, and refresh the same tab once.
- Idle eBay pages no longer run workflow page inspection when no resumable task exists.

## Marketplace Boundaries

- Move .99 remains bound to one run, one owner tab, exact item IDs, bounded batches, and an untouched final eBay Submit.
- Mark as Shipped still stops at eBay Continue with an exact selected count.
- eBay order notes fill but never click eBay Save.
- Amazon automation submits only read-only order-history searches and never places an order.
- Walmart refuses final purchase controls.
- Poshmark historical profit backfill pauses across an update and requires explicit Resume.

## Retired Automation

- Removed every runnable GLDN seller-click, multipage extraction, recovery-probe, and Bulk Listing queue path for EcomSniper.
- Removed legacy local-helper checkpoints, buttons, status claims, and completion language.
- GLDN can open and observe its own EcomSniper handoff tabs; EcomSniper remains responsible for Scanner, Product Hunter, Bulk Poster, and listing controls.

## Security and Packaging

- Saved marketplace history is escaped before popup or universal-panel HTML rendering.
- No dashboard secret is committed to the public runtime configuration or release package.
- The universal panel still requires broad HTTP/HTTPS page access by design, but marketplace actions remain scoped to their own adapters.
- Existing Chrome profiles should use Update & Reload. Computers still running the older updater agent need the v3.11.0 one-time updater setup once; this upgrades the updater without replacing Chrome profile settings. Later releases need only Update & Reload.

## Verification

- Candidate source syntax and focused workflow contracts pass.
- The complete restored JavaScript suite, generated-guide drift check, updater fixtures, credential-free package build, and full release gate pass before publication.
- Signed-in Chrome Profile 2 / computer `0` / FAK12 is the only accepted live browser for final launch proof.
- No marketplace Continue, Save, Submit, purchase, or equivalent final action is authorized by this release note.
