# GLDN Ops v3.12.3

## What changed

- Requires a permanent Amazon profile name before eBay or Poshmark missing-cost reconciliation starts.
- Records the exact Amazon profile that attempted every reviewed order.
- Filters the shared queue so the same Amazon profile cannot receive the same unresolved rows again.
- Directs the operator to another signed-in Amazon profile when the current profile has no eligible rows left.
- Deploys the matching queue contract in Google Apps Script dashboard revision 45.

## Safety

- No eBay API is used.
- Amazon reconciliation is read-only until the exact count-bound dashboard sync approval.
- Unresolved costs remain blank and open; GLDN Ops does not guess an Amazon order or cost.
- Existing eBay note evidence remains separate from independently matched Amazon order evidence.
- No eBay listing, order, or Amazon purchase is changed by this workflow.
