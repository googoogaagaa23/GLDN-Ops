# GLDN Ops v3.11.5

## Scope

- Stop extension updates from refreshing every open marketplace tab.
- Preserve the requesting-tab activation path, verified updater, settings, rollback snapshots, and all marketplace approval boundaries.

## Update Isolation

- Update & Reload, Reload Current Files, and rollback record the exact requesting Chrome tab.
- After the runtime reload, only that exact tab is refreshed into the new content-script version.
- Every unrelated eBay, Amazon, Poshmark, Walmart, EcomSniper, and ordinary webpage tab remains untouched.
- An old content script disables its own GLDN controls and asks for a manual refresh instead of reloading the host page.
- A background shared-folder version change reloads the extension runtime without refreshing any webpage.

## Marketplace Safety

- This release grants no marketplace approval.
- Mark as Shipped still stops before activating eBay's command and again before eBay Continue when shown.
- Move .99 and reverse category cleanup still stop before every eBay Submit.
- Order notes still stop before eBay Save.

## Verification

- Regression tests must prove that the requesting tab ID is retained across the service-worker reload and that bulk marketplace-tab refresh code is absent.
- The full JavaScript suite, syntax checks, updater fixtures, generated-guide drift check, package inspection, and release gate must pass.
- Signed-in Chrome Profile 2 must then prove v3.11.5, preserved computer `0` / FAK12 identity, dashboard health, and a targeted update/reload with unrelated tabs unchanged.
- No marketplace Continue, Save, Submit, purchase, or equivalent final action is authorized by this release note.
