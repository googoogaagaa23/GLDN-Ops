# GLDN Ops v3.10.0

## Scope

- Replace manual ZIP replacement with a one-time, no-admin Windows updater.
- Keep one stable extension folder per computer and preserve per-Chrome-profile settings.
- Add verified Update & Reload, current-file reload, and rollback controls.
- Keep all marketplace approval stops unchanged.

## Safety

- The agent listens only on `127.0.0.1` and accepts fixed status, update, version-list, and rollback operations.
- Update URLs come only from the fixed public stable metadata document; browser messages cannot supply an arbitrary package URL.
- Every package must match its published SHA-256 and manifest version before the installed extension folder changes.
- The existing runtime is snapshotted before replacement. Failed replacement restores that snapshot.
- `config.js` and Chrome profile storage remain intact. The updater never clicks, saves, submits, purchases, or changes marketplace data.
