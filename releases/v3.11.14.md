# GLDN Ops v3.11.14

## What changed

- Move `.99` and reverse cleanup now apply verified matches through exact eBay item-number workspaces.
- Each workspace contains at most 500 verified listings and is selected with eBay's native table-header select-all control.
- The workflow no longer depends on clicking each matching row or re-matching every row by title and price when eBay admits the complete exact batch.
- eBay's native selected count and final Submit count must both equal the admitted batch.
- Fixed the final verification page counter so an explicit eBay result cannot be followed by a false `stopped safely` error.
- Every final eBay Submit remains untouched until separate action-time approval.
