# GLDN Ops v3.12.58

Date: 2026-10-19

## Orders Left Reader Recovery

The counter now reads a stable native order table without waiting for unrelated images and other page resources to finish loading. Reader injection runs immediately, with bounded response waits and a longer native-read recovery window.

Helper ownership uses the saved source tab, run and helper role instead of transient opener/window metadata. Switching to another tab or moving the source or reader to a different window in the same browser profile does not invalidate the read. Remounting the inline summary reconnects to the existing run rather than starting another one.

A discarded helper reloads once without taking focus. A frozen helper shows Open reader so the operator can let the browser resume it. Sign-in, verification, unexpected navigation, changed accounts/filters and incomplete native evidence remain explicit partial reads. Exact order identity and normal/incognito boundaries are still checked.

All counting rules are unchanged: any saved note excludes an order, canceled/cancelled orders are ignored, and multiple items in one order count once. No order or note is created, edited, purchased, shipped or canceled.

## Verification

- Seven new background regression tests cover reading while browser status is loading, switching/moving tabs, saved-reader identity rejection, changed filters, normal/incognito separation, discarded helpers and frozen-reader recovery.
- Isolated real-extension Chromium checks pass at desktop and narrow-screen sizes with a deliberately unfinished page resource, another tab selected, the source moved between windows, and the inline summary remounted during the same run.
- Existing fixture coverage still reads three pages with nine mixed orders and 235 larger-set orders, resolves hidden notes, updates visible saved notes and distinguishes genuine empty results from partial reads. No customer account or marketplace submission is used.
- The affected signed-in Chrome/Edge browser is not currently exposed to browser control. Current signed-in and formal video verification remain pending; these fixtures are not a LIVE PASS.
