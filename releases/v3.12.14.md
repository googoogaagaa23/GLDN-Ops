# GLDN Ops v3.12.14

## What changed

- eBay responses such as `Listing item is missing` no longer count as successful listing Ends.
- Existing Listings Policy Audit now exposes **Cancel Review & Rescan** whenever a native review is stranded or stale.
- Starting a fresh scan while a review is open cancels only the saved review and begins a complete read-only Active Listings scan.

## Safety

- Canceling a review does not end, edit, or delete any eBay listing.
- A failed or ambiguous eBay response is stored as unresolved and never enters the successful-End ledger.
- Every future listing End remains blocked behind a new visible eBay review and exact `APPROVE END POLICY LISTINGS N` authorization.

## Verification

- Focused regression coverage includes the exact `Listing item is missing` response and explicit mixed per-listing failures.
- The complete release gate verifies parsing, packaging, updater checksums, clean install, rollback, and all JavaScript contracts.
- Signed-in Profile 2 post-recovery read-only scan evidence is recorded separately after release reload.
