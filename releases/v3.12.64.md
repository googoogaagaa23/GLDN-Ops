# GLDN Ops v3.12.64

Date: 2026-10-25

## Amazon And Trackerbot Order Links

Order links appears on native eBay order-details and return pages. Find Amazon order reads the saved note's profile label and product SKU. Return pages that omit that information use the exact linked order details in an inactive reader.

Trackerbot's native search is restricted to the exact eBay order number. GLDN reads supplier order ID and supplier email from that row, waits for loading to settle and highlights the matches. Repeated shipment rows deduplicate; multiple supplier orders or conflicting account evidence stop for manual review. Open Trackerbot leaves that native search visible without uploading, converting or editing anything.

Profiles maps a label such as TIFF to an existing Chrome profile on the same computer, with an optional supplier email cross-check. The Windows helper opens a canonical Amazon order-details link in that mapped profile. If no supplier order is found, one exact ASIN may instead open a clearly labeled purchase-history search; it is never represented as a verified purchase. The helper does not accept arbitrary URLs or commands, inspect cookies or transfer sessions. Amazon may still require sign-in.

Minimal saved links and mappings stay under local app data on that computer, outside the replaceable install directory. This feature does not save passwords or buyer addresses and does not send records to the shared dashboard.

## Computer Helper Requirement

Run the latest GLDN Ops Setup once on each computer to install helper v1.2.0. Update & Reload updates extension files only and cannot add this new helper endpoint. Each computer keeps its own explicit label-to-Chrome-profile mappings. There is no remote-computer routing and no automatic account inference from Chrome display names.
