# GLDN Ops v3.12.18

## What changed

- Monthly eBay Profit now keeps two genuinely independent profit reads.
- Read 1 uses only the saved eBay note: note earnings minus note Amazon cost.
- Read 2 uses visible eBay order earnings minus the exact matched Amazon order-item cost.
- Both values remain visible side by side, including earnings, costs, profits, and differences.
- Harmless formatting errors in note money values are normalized automatically.
- Ambiguous characters, likely missing decimals, and note-versus-visible earnings differences open an editable confirmation review instead of being guessed into totals.

## Safety

- Confirming a suggested amount changes only GLDN Ops internal profit evidence.
- The confirmation never edits an eBay note, order, listing, or Amazon order.
- Unconfirmed ambiguous values remain excluded from exact note-only totals.
- Exact Amazon matching, supplier-profile separation, date windows, and approval-bound dashboard writes are unchanged.
