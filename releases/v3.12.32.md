# GLDN Ops v3.12.32 - Local Reliability Release

## Changes

- Cancellable review registration and ordered cleanup; unrelated approvals remain blocking.
- Explicitly paired control identities work with shared multi-profile extension folders. No webpage heartbeats; unavailable agents back off. State-changing commands are never automatically redispatched after a lost response.
- Health & Installations shows runtime, identity, updater/file/release versions, saved progress, review owners, queued records, and recent issues.
- Plan-first Chrome policy setup preserves unrelated entries. The separate complete Web Store package uses Chrome-managed updates.
- The local installer now includes all three workflow-guide files and rejects any future public runtime omission.

## Upgrade Boundary

This release uses the existing GitHub/local updater and requires no Chrome Web Store approval. Existing installations use Update & Reload. New pairing and installation inventory require Windows helper v1.1.0: run the current one-time Setup once per computer if the helper is older. A fresh Chrome profile still needs Load unpacked once; no unpacked extension is silently installed into other profiles. Preserve the current loaded folder so the Chrome identity, settings, and checkpoints stay intact. Marketplace and shared-sheet writes retain their separate approval gates. Pairing credentials are not included in settings backups.
