# GLDN Ops v3.12.55

Date: 2026-10-12

## Unread Customer Messages

Fix the early Complete result when eBay's next-page control or scrolling container was not recognized. The scanner now follows native paging and traverses lazy/virtual scrolling lists in overlapping viewport steps. It does not stop simply because the first batch matches a badge count.

Complete requires an identified native last page, a genuine empty folder, or a settled bottom-of-list load-more probe. Native unread counts must remain unchanged and reconcile with the distinct conversations collected. Loading folders, unknown navigation, repeated pages, count changes and unidentified unread rows remain Partial.

The native Unread from members folder is preferred over generic unread controls. Customer preview wording cannot masquerade as an empty-inbox notice. Prior unverified Complete labels are downgraded without removing saved messages, per-account ignores or Restore preferences. Resume does not double-count a saved batch. Exact conversation opening can traverse later pages and scrolling batches.
