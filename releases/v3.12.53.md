# GLDN Ops v3.12.53

Released 2026-10-06.

## Shared Audit Reliability

Dashboard requests now use a fresh URL and disable caching. Google Apps Script ContentService returns one-time response redirects; reusing an old redirect can land on the dashboard's HTML page instead of its JSON response. Transient read failures retry within a bounded limit; authorization failures and writes are not blindly replayed. Amazon completion uses a stable write receipt to recover a lost response without a duplicate write.

The shared server was upgraded to Apps Script version 52. Existing date-formatted month cells read back as YYYY-MM, and new audit month cells are protected as text. The deployment URL and unrelated dashboard/checkbox functions remain unchanged.

Purchases outside every corresponding eBay order's matching date window are retained under Needs Review, not counted as duplicate or extra purchases. Unknown dates also require review. Valid in-window duplicate detection and cross-profile purchase deduplication remain active.
