# GLDN Ops v3.12.48

Released: 2026-10-04

## Amazon ETA

Selected shipment headings such as Arriving Tomorrow 7 AM - 11 AM automatically
fill the next local calendar date. On October 4, the result is 10/5. Today uses
the current local date. Calendar arithmetic handles month/year rollover, leap
days and daylight-saving changes. Keep the computer's date and time correct.

An explicit date in the heading wins. Unselected Fastest/Amazon Day choices and
ambiguous relative date ranges do not become additional shipment dates. Manual
ETA corrections in the review remain untouched.

## eBay Note Menu

Fill eBay note recognizes Add order note, Edit order note, Add note and Edit note.
It selects native controls rather than text in GLDN's own messages, reuses an
already-open menu and waits for delayed menu rendering. Multiple distinct targets
or a changed order stop the operation rather than guessing.

The final eBay Save is still manual. This fix does not place an Amazon order,
change an address or turn a checkout draft into verified purchase/profit evidence.
