# GLDN Ops v3.12.52

Released 2026-10-06.

## Order Audit Recovery

Order Placement Audit now distinguishes a missing eBay read from a broken shared connection. Build is enabled only for a completed read matching the selected computer, account and month. The saved demand is read back unit by unit before success is reported. Amazon-only profiles, including the local-control route, can scan shared demand without a local eBay monthly read.

Failed refreshes clear stale results; older responses cannot restore a different audit after switching targets. Partial, duplicated or mismatched demand cannot start a worker, and repeated clicks cannot reset the audit twice. The page includes Open Monthly eBay Profit and responsive controls.

## Verification

- Live anonymous dashboard requests returned Google Access Denied. The signed-in owner reached Authorization needed, confirming owner renewal is required. The existing dashboard URL and saved data are retained.
- Automated checks cover Amazon-only profiles, wrong computer/account/month, partial uploads, unit-level build readback, stale and out-of-order refreshes, duplicate clicks and readable non-JSON errors.
- Shared-server recovery depends on completing Google's owner authorization. Signed-in M0/M7 end-to-end audit completion is not claimed.
- The audit never purchases, cancels, refunds, ships or changes marketplace orders.
