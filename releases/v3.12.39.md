# GLDN Ops v3.12.39

## Changes
- Check eBay Result is available for batches ended directly on eBay, without reentering an End approval.
- Individual proven ended items update the ledger. Inactive rows merely hidden for policy violations are not falsely marked ended.
- Set Aside Batch & Continue retains unresolved exact IDs and frees other selected Block or Review items. Unconfirmed IDs cannot reenter an extension End batch.
- Check Saved Batch Result can reconcile older batches without disturbing the current batch.
- Updates preserve v3.12.38 native review evidence while revoking the old End approval. No automatic End retry, private eBay endpoint, or policy-rule changes.

## Recovery on M0
1. Keep the native eBay review tab open. Do not Reset or discard the old review before updating.
2. Install v3.12.39. If v3.12.38 blocks its own Update & Reload, run the existing GLDN Ops installer/update tool, then use Chrome's extension management page to reload GLDN Ops. Reopen the audit.
3. Click Check eBay Result for the saved 56-item batch. This only reads eBay; it never submits End again.
4. If some items remain unconfirmed, choose Set Aside Batch & Continue. They are retained separately, not counted as ended.
5. Filter Review, select the desired flags, and open the exact next batch on eBay. Each new batch needs its own approval.
