## Orders Left To Place

An inline summary on eBay Orders automatically counts unique orders without a saved note and excludes canceled/cancelled orders. Any saved note counts as placed, regardless of wording. Multiple items in one order count once.

Remaining orders are grouped oldest-first by native order date, with the actual weekday and month/day: `Thursday, 10/15 50 orders left`. Older years include the year. Visible calendar text takes priority over timestamp attributes.

The read follows every native page in the current eBay filters, beginning from page one in an inactive helper tab while leaving the visible page unchanged. Hidden or uncertain note/date/status fields are checked through the exact order detail link. The native More actions menu may be opened to identify Add order note versus Edit order note; neither is clicked or saved.

Visible saved-note and cancellation changes refresh the total. Recount checks all pages again; Stop retains clearly partial results. Unknown navigation, incomplete result ranges, unreadable notes, account/filter changes and sign-in problems never become a verified zero. No order is placed, canceled, shipped or edited. This counter sends no data to the shared dashboard.
