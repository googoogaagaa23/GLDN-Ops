# GLDN Ops v3.12.20

## What changed

- Monthly eBay Profit no longer closes its own worker tab when eBay page verification fails.
- The failed signed-in eBay page remains open and the monthly run changes to Paused with the exact reason.
- Resume reuses that preserved worker tab instead of opening another one.
- All Orders can be verified from eBay's encoded status URL when selected-navigation metadata is absent.
- Alternate nested All Orders and Period controls are now supported.

## Unchanged behavior

- A deliberate Pause, Reset, completed detail read, or completed review still cleans up the intended worker.
- eBay interruption, identity challenge, and CAPTCHA pages remain blocked rather than being treated as order evidence.
- Read 1 remains saved-note earnings minus saved-note Amazon cost.
- Read 2 remains visible eBay earnings minus the exact matched Amazon order-item cost.
- No order, listing, note, purchase, or spreadsheet write occurs during worker recovery.

## Verification

- Focused tests cover URL-based All Orders recognition, alternate control discovery, preserved failure tabs, Resume reuse, and normal cleanup.
- The complete JavaScript and release suites must pass before updater publication.
- Live M0 confirmation remains the final runtime check for the cross-computer eBay layout.
