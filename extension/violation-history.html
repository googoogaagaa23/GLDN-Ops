Step-by-step guide
  1. Use the Chrome profile signed into the eBay store you want to check.
  2. Choose Scan This eBay Account. GLDN opens Inactive, follows View Listings, and reads every violation row and available case explanation. No listing is changed.
  3. Wait for Shared history verified. Pause and Resume keep completed reads. If sharing fails, choose Sync Shared History after checking your dashboard connection.
  4. Repeat the scan on each eBay profile. Every updated GLDN profile using the same dashboard receives the combined history during policy checks.
  5. Exact ASIN matches are blocked. Closely matching titles need review and are excluded from Ready links. A related match is a prevention warning, not proof of a policy violation.
  6. Use Refresh Policy Checks in an existing saved audit to apply newly shared incidents without reading the whole store again.
