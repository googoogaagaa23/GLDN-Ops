Feature guide

Short operator steps for the main GLDN Ops workflows.

Daily panel
  1. Use Side or minimize when the panel blocks the page.
  2. Use Update & Reload to install a verified stable release. Use Reload Current Files only when a panel is stale.
  3. Use Stop Task to stop at the next safe checkpoint.
  4. Use Reset only when a saved workflow is stuck.
  5. Use Dashboard to open the shared dashboard.
Mark as shipped
  1. Open the eBay orders page.
  2. Click Mark as Shipped.
  3. Review any eBay confirmation before continuing.
Prepare order note
  1. Open Amazon checkout/order info and copy Amazon info.
  2. Open the matching eBay order.
  3. Click Prepare Order Note.
  4. Review the note, then Fill Add Note Box.
  5. Manually click eBay Save after reviewing.
  6. The same values are saved to the per-computer profit sheet when dashboard sync is reachable.
Seller level and limits
  1. Open Seller Hub performance or overview.
  2. Run Scan Seller Level or Confirm Listings Under Limit.
  3. Use Scan Sales Snapshot from Seller Hub Overview for sales, feedback, traffic, and advertising data.
  4. Review detected values before saving.
  5. Saved values sync to the dashboard and Tasks sheet.
  6. Metric alert rows show CHECK plus the affected computer names.
Move .99
  1. Set exact source and destination Store category names.
  2. Click Save .99 Categories for This eBay.
  3. Click Open Move .99 Workflow.
  4. Review the scan summary before applying changes.
  5. Stop at eBay review unless final Submit is approved.
EcomSniper handoffs and sniping
  1. Use the Handoff monitor for GLDN-observable seller extraction and EcomSniper tab status.
  2. Use Sniping Workflow from a specific Amazon product with a visible price.
  3. Keep EcomSniper responsible for scanner, Product Hunter, and listing work.
  4. GLDN Ops clicks EcomSniper Extract Sellers and continues only when the before total, after total, and new-seller count reconcile.
  5. Do not treat an open EcomSniper tab as proof that Bulk Poster is running or complete.
  6. If it does not continue, use Copy Full Diagnostic Report before resetting.
Poshmark tools
  1. Save computer 7 for the Poshmark Chrome profile.
  2. Open Poshmark Stats and run Scan Posh Stats for closet performance values.
  3. Use Capture Visible Sales on a Poshmark sales list to log visible order rows.
  4. For full profit, open the Poshmark sale order and click Capture Order Profit.
  5. If Amazon is not matched yet, use Open Amazon Orders for the decoded SKU ASIN.
  6. Open the matching Amazon order, then click Review & Copy Amazon Info.
  7. Return to the Poshmark sale order and click Capture Order Profit again.
  8. Review earnings, Amazon total, profit, SKU, and order number before saving.
Popup tools
  1. Open Amazon Best Sellers starts manual product research.
  2. Open EcomSniper Competitor Scanner opens EcomSniper research.
  3. Open EcomSniper Product Hunter opens the EcomSniper product tool.
  4. Check EcomSniper Mode confirms automatic semantic-click mode.
  5. Run Feature Health Check tests dashboard access, EcomSniper page routing, click mode, and saved identity.
Settings
  1. Save Computer once per Chrome profile. The eBay/Poshmark account is derived from the computer.
  2. Set Interface theme and transparency for GLDN Ops windows.
  3. Save Amazon Profile inside Amazon Chrome profiles only.
  4. Use Test Connection before trusting dashboard sync on a new install.
Diagnostics
  1. Open this popup after an error.
  2. Click Copy Full Diagnostic Report for cross-computer issues, dashboard failures, EcomSniper stalls, and install/update problems.
  3. Click Copy Error Log.
  4. Send the copied text with the page and button used.
Settings backup
  1. Click Copy Settings Backup before updating or moving a Chrome profile.
  2. After reinstalling or updating, click Restore From Clipboard.
  3. Confirm the computer, Amazon profile, listing limits, UI settings, and Move .99 categories still look right.
