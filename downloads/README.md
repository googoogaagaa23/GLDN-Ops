# GLDN Ops Downloads

## Recommended one-time setup

- [Download GLDN Ops Setup](./GLDN-Ops-Setup.exe)

Run Setup once on each Windows computer. It creates the stable
`%LOCALAPPDATA%\GLDN Ops\extension` folder and installs the hidden verified
updater. Load that stable folder once in each intended Chrome profile. Later,
use **Update & Reload** inside GLDN Ops; do not download another ZIP.

SHA-256:

`E05772109DEA887D42A4FBD43AD12B0286AB29FE59B75B32BB657C5EB3B0E375`
